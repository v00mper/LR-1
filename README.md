# Лабораторная работа № 1

## Вариант № 2 — «Изменение образца заполнения прямоугольника»

Программа отображает прямоугольник в графическом окне.
Пользователь может перемещать его стрелками и переключать узор заполнения.

## Описание задачи

Построить прямоугольник с заданными координатами.
При нажатии стрелок перемещать прямоугольник, а при нажатии
PgUp и PgDn циклически изменять образец заполнения его внутренней области.
Выход из программы — по клавише Esc.

## Возможности программы

- Перемещение прямоугольника на 10 пикселей за нажатие.
- Ограничение перемещения границами окна.
- Четыре образца заполнения: горизонтальные линии, вертикальные линии,
  сетка и диагональные линии.
- Циклическое переключение образцов.
- Завершение по Esc или при закрытии окна.

## Среда выполнения

- Язык программирования: Python.
- Версия Python при разработке: 3.14.10.
- Библиотека: pygame-ce 2.5.8.
- Среда разработки: Visual Studio Code.
- Операционная система: Windows.

## Управление

- Стрелка влево - переместить прямоугольник влево.
- Стрелка вправо - переместить прямоугольник вправо.
- Стрелка вверх - переместить прямоугольник вверх.
- Стрелка вниз - переместить прямоугольник вниз.
- PgUp - следующий образец заполнения.
- PgDn - предыдущий образец заполнения.
- Esc - завершить программу.
- Крестик окна - завершить программу.
